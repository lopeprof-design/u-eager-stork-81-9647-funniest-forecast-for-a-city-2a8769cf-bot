Funniest Forecast for a City That Isn't — one line, in the flat phrasing of an
official weather bulletin: in Bluster Bay the gale blows the bins airborne by
noon and the mayor gets rescheduled to Thursday, so residents are told to hold
on to their neighbours.

## Run it

```sh
node main.ts
```

Writes the single forecast line to `/output/entry.txt` (1–120 characters,
as the gate requires).
